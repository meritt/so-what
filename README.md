«Чтобы что» — скилл `so-what` для ИИ-агента, который помогает довести смутный замысел до идеи, видения, цели или задачи, которую человек узнаёт как свою.

Работает в Claude (Claude Desktop, Claude Code), в Codex и в любом агенте с поддержкой формата [Agent Skills](https://agentskills.io).

## Замысел

Когда человек ещё не может сказать, чего хочет и зачем, обычный агент делает одно из двух: присылает анкету из пяти вопросов или выдаёт готовый план с выдуманными сроками, бюджетом и метриками. В первом случае думать снова приходится человеку, во втором за него уже подумали.

«Чтобы что» делает третье: предлагает конкретную пробную формулировку, которую можно узнать, отвергнуть или поправить. Каждый ответ меняет понимание, а не только слова.

Разделение ролей:

- **за человеком** замысел, ценности, компромиссы и решения;
- **за агентом** качество формулировок, честность о том, откуда взялась каждая часть, связность целого и карта работы.

## Как ведёт себя скилл

- **Обычный ход короткий.** Что понято, одна своя мысль с пометкой, что она своя, и одно различение на проверку. Без анкет, меню и заголовков.
- **Слова человека сохраняются с их силой.** «Хотелось бы» не превращается в требование, «меньше звонков» не становится целью «минус 20%».
- **Короткое «да» подтверждает главное**, а не каждое предложение из длинного ответа. Добавки агента остаются предложениями, пока их не приняли.
- **Поправка меняет понимание целиком**: пересматривается всё, что от неё зависело. «Близко, но не то» без объяснений — законный ответ.
- **Противоречия называются с основанием**: какие два утверждения сталкиваются, при каком условии и что можно сдвинуть. Агент говорит, какой вариант выбрал бы сам, а решение оставляет человеку.
- **Ничего не выдумывается.** Неизвестные числа, сроки, бюджеты и ответственные так и помечаются: неизвестно.
- **Когда слов мало, нужна проверка в мире**: что проверяем, каким действием, какой сигнал засчитаем и какое решение от этого зависит.
- **При тупике меняется посылка, а не прилагательные**: другой участник, масштаб или горизонт, или условия вместо людей.

## Результат

Глубина такая, какая нужна сейчас, полный набор данных не обязателен. Возможные результаты:

- идея;
- картина результата или видение;
- цель;
- задача для исполнителя;
- план проверки;
- промежуточное сохранение с открытыми предпосылками.

В каждом результате раздельно видны намерения человека, согласованные формулировки, принятые решения, допущения агента, известные факты, открытые вопросы и следующий шаг.

## Карта замысла

Работу можно продолжить в другой сессии. Там, где агент пишет файлы, которые сохраняются между сессиями (Claude Code, Codex), он ведёт `so-what/<short-name>.md` в рабочей папке. В карте записано:

- что принято, предложено и отвергнуто, и почему;
- что подтверждено фактами;
- какие записи зависят друг от друга.

В чатах без постоянных файлов (claude.ai) карта выдаётся блоком, который вставляют в начало следующего разговора. О сохранении скилл сообщает только после успешной записи. Если карты нет, он так и говорит и не восстанавливает прошлое по догадкам.

## Установка

Репозиторий одновременно служит маркетплейсом плагинов для Claude и Codex и источником для `npx skills`.

### Claude Code

```
/plugin marketplace add meritt/so-what
/plugin install so-what@so-what
```

То же из терминала:

```bash
claude plugin marketplace add meritt/so-what
claude plugin install so-what@so-what
```

### Claude Desktop и Cowork

Через маркетплейс: **Customize → Plugins → Add → Add marketplace**, ввести `meritt/so-what` и установить плагин `so-what`. Установка привязана к аккаунту и действует в вебе, в Desktop и в Cowork.

Через ZIP:

1. Скачать архив [`so-what.zip`](https://github.com/meritt/so-what/releases/latest/download/so-what.zip) из последнего релиза.
2. Включить **Settings → Capabilities → Code execution and file creation**.
3. Открыть **Customize → Skills → + → Create skill → Upload a skill** и загрузить архив.

### Codex

```bash
codex plugin marketplace add meritt/so-what
codex plugin add so-what@so-what
```

Только скилл, без плагина, можно поставить изнутри сессии Codex:

```
$skill-installer install https://github.com/meritt/so-what/tree/main/skills/so-what
```

### npx skills: любой поддерживаемый агент

```bash
npx skills add meritt/so-what
```

Харнессы можно указать явно: `-a claude-code -a codex`. Флаг `-g` ставит скилл глобально, а не в текущий проект.

## Версии и обновления

Каждый релиз — тег `vX.Y.Z` с архивом `so-what.zip`.

| Где | Закрепить версию | Обновить |
|---|---|---|
| Claude Code | `/plugin marketplace add meritt/so-what#v0.1.0` | `claude plugin update so-what@so-what`. Автообновление сторонних маркетплейсов включается в `/plugin` → Marketplaces |
| Claude Desktop, Cowork | — | Check for updates или Sync automatically у маркетплейса. Архив: удалить скилл и загрузить новый |
| Codex | `codex plugin marketplace add meritt/so-what --ref v0.1.0` | `codex plugin marketplace upgrade so-what` |
| npx skills | `npx skills add meritt/so-what#v0.1.0` | `npx skills check`, затем `npx skills update` |

## Как работать

Скилл включается сам, когда человек не может сформулировать, чего хочет, зачем это нужно или о чём попросить других. Вызвать его явно:

| Где | Команда |
|---|---|
| Claude Code, установка плагином | `/so-what` |
| Claude Code, установка через `npx skills` | `/so-what` |
| Codex | `$so-what` |

Начинать можно с самой сырой фразы: «хочу что-то сделать для команды, но сам не понимаю что».

Что помогает по ходу:

- отвечать коротко: «не то», «ближе», «ну да» — тоже ответы;
- спрашивать «что уже решено?», «что открыто?», «почему мы это отбросили?»;
- сказать «хватит», чтобы зафиксировать рабочую версию;
- попросить черновик, когда материала уже достаточно.

## Пример

Сокращённый диалог из проверочного прогона.

> **Человек:** Хочу сделать что-то для соседей по дому. Типа клуба, наверное, но не совсем. Сама не понимаю.
>
> **Агент:** Может быть, «не совсем» как раз про то, что в клубе есть членство, расписание и обязательства, а вам видится что-то полегче? Расскажите про недавний случай с соседями, после которого эта мысль появилась.
>
> **Человек:** прошлой зимой у нас на пятом валентина петровна упала дома и почти сутки пролежала, пока сын не приехал. а мы с площадки узнали только через неделю.
>
> **Агент:** Похоже, речь не о досуге: с человеком через стенку случилась беда, а соседи узнали последними. Если так, «что-то для соседей» скорее про то, чтобы знать друг о друге настолько, чтобы заметить, когда с кем-то неладно.
>
> **Человек:** да, вот это ближе. только чтобы именно замечали, а не присматривали, никто ни за кем следить не должен.
>
> *…ещё несколько ходов…*
>
> **Человек:** и хочется, чтобы за каждым пожилым кто-то гарантированно каждый день присматривал.
>
> **Агент:** Это сталкивается с тем, что вы ставили раньше: «никто ни за кем следить не должен». Гарантия «каждый день» держится только на том, что конкретный человек обязан прийти, даже когда ему некогда. Мне ближе знакомство и «замечать» без обязательств для всего дома, а ежедневный контакт только там, где пожилой сосед сам этого хочет и кто-то сам на это согласился. Захотят ли этого пожилые соседи, пока неизвестно. Что для вас важнее?
>
> **Человек:** наверное важнее, чтобы заметили за день-два, а не чтобы каждый день кто-то заходил.

Итог разговора — черновик сообщения в чат дома. Нерешённый последний шаг помечен в нём как нерешённый, а не заполнен за автора.

Что здесь сделал скилл:

- вместо анкеты попросил один конкретный случай;
- сохранил различение «замечать, а не присматривать»;
- назвал противоречие с основанием и своим вариантом;
- не выдумал ни одной цифры.

## Состав репозитория

```
skills/so-what/          скилл: SKILL.md и справочники references/
assets/                  иконка плагина и её версия для README
.claude-plugin/          манифест плагина и маркетплейса для Claude
.agents/plugins/         маркетплейс для Codex
plugin.json              переносимый манифест Agent Plugins с карточкой Codex
scripts/release.py       проверка скиллов и манифестов, сборка архивов
```

Скилл разрабатывается и проверяется эвалами и тестами в рабочем репозитории автора. Сюда синхронизируются выпуски.
